# Nắng Thu - Nhất Linh

## Thông tin tác phẩm

- Tác phẩm: Nắng Thu
- Tác giả: Nhất Linh
- Giới thiệu: Tác phẩm Nắng Thu của nhà văn Nhất Linh là một truyện dài lãng mạn nổi tiếng, kể về mối tình nhẹ nhàng, tinh tế giữa chàng Phong và cô bạn gái thuở nhỏ Trâm, diễn ra trong bối cảnh quê hương yên bình, khắc họa tình yêu tuổi trẻ, sự nhớ nhung và rung động đầu đời.
